# 단어 데이터 검수 기록

2026-10-20, N5~N1 8,024개. 기존 N5~N2 5,333개와 새 N1 2,699개를 대조하고, 정규화 후 중복 8개를 기존 ID 연결로 정리했다.

## 실행 자료와 기록 호환성

앱은 `public/data/vocabulary.json`을 읽는다. `meaningDetail`은 뜻 설명, `example`은 일본어 예문과 선택적인 한국어 번역·원문 ID·작성자다. 부수의 `original`은 원래 한자, `variant`는 해당 글자에서 쓰이는 모양이다. `wordAliases`는 정리한 기존 ID와 현재 ID를 연결한다.

데이터나 ID를 바꾸면 `tests/fixtures/legacy-word-ids.json`의 기존 5,333개 ID가 모두 해석되는지 검사한다.

## 보관한 교정 자료

- `quality-audit.json`: 개수, 뜻 변경, 표기·읽기 교정과 ID 연결
- `meaning-corrections.json`: 새로 작성한 한국어 뜻과 추가 교정 자료
- `original-examples.json`: 프로젝트 작성 예문과 한국어 번역. 같은 키의 뒤 항목은 앞 항목의 추가 교정이다.
- `final-corpus-review.json`: 외부 예문 전체의 형태·읽기·품사 검사 결과와 307개 경고 항목, 추가 동음이의어 15개에 대한 문맥 검토 기록. 해시는 추가 교정 전 검토 대상 자료를 가리킨다.
- `final-corpus-fixes.json`: 해당 검토에서 작성한 예문 교체 64개와 뜻 교정 41개. 겹치는 항목을 포함한 88개 ID에 적용했다. `original-examples.json` 뒤에 적용되는 최종 교정이다.

이 파일들은 검토용이며 앱 실행에는 합쳐진 vocabulary.json만 필요하다. 대용량 원본 사전·연구용 임시 자료·인증 정보는 저장소에 포함하지 않는다.

## 검수 방법과 범위

1. Open Anki 표기·읽기와 기존 ID를 대조하여 N1을 통합했다.
2. 국립국어원 한국어기초사전의 일본어 대역·한국어 정의를 대조하고, 위키낱말사전의 어간·다른 품사·다른 읽기 설명을 구분했다.
3. 직접 연결되지 않은 1,478개 항목의 한국어 뜻을 일본어 표기·읽기와 JMdict 뜻을 참고하여 작성했다. 낮은 일치도의 후보 549개도 추가로 검토했다.
4. 뜻에 연결된 JMdict 예문을 우선 선택했다. Tatoeba 추가 예문은 원형·읽기·품사를 검사하고, 잘못된 연결이나 용례가 부족한 항목에는 새 예문을 작성했다.
5. 부수는 KANJIDIC2·KanjiVG·Unicode로 대조했다. 한자 1,974종 중 1,969종은 구조 자료로 확인했고, 全·夏·由·甲·申은 대표 부수 원형을 사용했다.
6. 전체 뜻·예문·고유 ID·필수 필드·등급별 개수와 기존 기록 호환성을 검사한다.

최종 자료에는 외부 예문 7,341개와 프로젝트 작성 예문 683개가 있다. 추가 검수에서는 あげる(주다), バス(버스), ボール(공), ボルト(전압 단위) 등 동음이의어의 뜻과 용례를 맞췄다. 외부 예문 전체를 대상으로 형태·읽기·품사를 검사했고, 자동 경고가 난 307개는 문맥을 추가 확인했다. 자동 검사를 통과한 모든 문장의 세부 의미까지 수동으로 증명한 것은 아니다.

예: おととし는 재작년, 四角い는 네모나다, 湧く는 솟아나다, いただく는 받다·먹다·마시다의 겸양어다. 盛り/さかり와 もり, 琴/きん과 こと처럼 읽기에 따라 달라지는 뜻도 구별했다.

사전 대조·자동 검사·모델의 언어 검토를 결합한 검수다. 모든 다의적 의미를 망라하거나 원어민이 전 항목을 수동 검수한 자료는 아니다. 출처·뜻 번호와 예문 원문을 보존하여 이후에도 교정할 수 있도록 했다.

## 검증

`npm test`, `npm run typecheck`, `npm run lint`를 실행한다. 예문을 수정할 때에는 해당 읽기·품사의 실제 용례인지 확인한다. 어떤 단어든 넣을 수 있는 단어 암기 안내 문장을 사용 예문으로 대체하지 않는다.
