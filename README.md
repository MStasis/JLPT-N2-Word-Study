# Kotoba Loop

N5부터 N2까지의 일본어 단어를 빠르게 훑고, 4지선다 퀴즈로 전부 맞힐 때까지 반복하는 정적 학습 사이트입니다.

## 주요 기능

- N5·N4·N3·N2 및 한자/가나 단어 복수 선택
- 10~50개 단위의 신규 단어 우선 학습
- 한자·후리가나·한국어 뜻·대표 부수 카드
- 한자 읽기 → 뜻 순서의 2단계 4지선다 퀴즈
- 학습 회차 자동 저장, 회차 선택 복습 및 통합 퀴즈
- 학습 회차와 퀴즈 기록의 JSON 파일 내보내기·불러오기
- 단어·읽기·뜻 검색
- 오답 카드 확인, 오답만 재도전, 전체 재도전
- 모바일·태블릿·데스크톱 반응형 UI

학습 기록은 해당 브라우저의 `localStorage`에 저장됩니다. 자동 동기화 대신 기록 파일을 내보내 다른 기기에서 불러올 수 있습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

검증:

```bash
npm run build
npm run lint
```
