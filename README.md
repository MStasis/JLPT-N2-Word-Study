# Yomirevo (요미레보)

N5부터 N1까지의 일본어 단어를 예문과 함께 익히고, 4지선다 퀴즈로 반복하는 학습 사이트입니다.

## 주요 기능

- N5·N4·N3·N2·N1 및 한자/가나 단어 복수 선택
- 기본 5개, 5~50개 단위의 신규 단어 우선 묶음 학습
- 통학 중 한 단어씩 보기: 본 단어만 바로 저장하며 이전 카드로 돌아가도 중복 저장하지 않음
- 한자·후리가나·한국어 뜻·뜻 설명·일본어 예문 (작성 예문에는 한국어 번역도 포함)
- 부수의 원형과 실제 모양 표시: `水(물) → 氵`, `心(마음) → 忄`, `肉(고기) → 月`
- 한자 읽기 → 뜻 순서의 2단계 4지선다 퀴즈
- 학습 회차 자동 저장, 회차 선택 복습 및 통합 퀴즈
- 학습 회차와 퀴즈 기록의 JSON 파일 내보내기·불러오기
- 단어·읽기·뜻 검색
- 오답 카드 확인, 오답만 재도전, 전체 재도전
- 모바일·태블릿·데스크톱 반응형 UI

학습 기록은 해당 브라우저의 `localStorage`에 저장됩니다. 자동 동기화 대신 기록 파일을 내보내 다른 기기에서 불러올 수 있습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

검증:

```bash
npm run build
npm run lint
npm run typecheck
npm test
```

## 데이터

N5~N1 학습용 참고 어휘 **8,024개**입니다. N1 2,699개를 추가하고 기존 자료의 읽기·표기·뜻을 교정했습니다. 정리한 중복 ID 8개는 `wordAliases`로 연결하므로 기존 기록과 백업을 계속 읽을 수 있습니다.

모든 단어에 일본어 예문이 있으며, 뜻은 국립국어원 한국어기초사전·한국어 위키낱말사전과 별도 교정 자료로 보완했습니다. 검수 방법은 [data/README.md](data/README.md), 출처와 라이선스는 [DATA_SOURCES.md](DATA_SOURCES.md)에 정리했습니다. 등급은 공식 JLPT 어휘 목록이 아닌 학습용 참고 분류입니다.

React·TypeScript와 Next App Router 호환 vinext/Vite, Cloudflare Worker를 사용합니다. 단어장은 `/data/vocabulary.json`으로 불러오며 별도 회원 가입이나 원격 기록 서버를 사용하지 않습니다.
